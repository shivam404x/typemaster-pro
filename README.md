## 🌟 Key Features

### 1. 📖 Structured 24-Lesson Touch Typing Mastery
- **Stage 1 (Home Row)**: Foundation keys (`A S D F`, `J K L ;`, Spacebar).
- **Stage 2 (Top Row)**: `Q W E R T`, `Y U I O P` extensions.
- **Stage 3 (Bottom Row)**: `Z X C V B`, `N M , . /` tactile discipline.
- **Stage 4 (Capitalization & Punctuation)**: Shift keys, quotes, commas, periods.
- **Stage 5 (Numbers & Symbols)**: Numeric row and special coding symbols.
- **Stage 6 (Speed Mastery)**: Paragraph flow, muscle memory, and zero-look discipline.
- **Live Visual Aids**: Dynamic 2-hand finger guide with active finger highlights & 3D color-coded mechanical keyboard.
- **AI Biometrics & Heatmap**: 10-finger biometric accuracy analysis and weak key tracker.

### 2. ⚡ Speed Test Arena & AI Ghost Rival
- **Real-time Metrics**: Live WPM, Raw CPM, Accuracy %, and Instant Error tracking.
- **SVG Velocity Waveform**: Real-time velocity graph showing speed acceleration and consistency over time.
- **AI Ghost Rival**: Race head-to-head against an automated bot with configurable pace (30 WPM Beginner to 100+ WPM God-Tier).
- **Hardcore Modes**:
  - 👻 *Ghost Ink (Blind Mode)*: Typed words vanish from view to enforce true touch typing memory.
  - 💀 *Sudden Death (Strict Mode)*: A single typo fails the run immediately.
- Custom durations: 15s, 30s, 60s, 120s.

### 3. 💻 Code Lab IDE & Speech-to-Type Studio
- **Multi-Language Support**: Practice real developer code in JavaScript, Python, C++, HTML/Tailwind, and SQL.
- **Audio Dictation (Speech-to-Text)**: Use your microphone or listen to dictated voice phrases to type by ear.
- **Custom Text Importer**: Paste any article, book excerpt, or code snippet to generate instant typing drills.

1. 🚀 **Typing Asteroids 3D**: Blast deep space asteroids before they collide with Earth.
2. 🏎️ **Neon Cyber Nitro Racer**: Shift gears and out-speed rival racers on synthwave tracks.
3. 🧟 **Zombie Horde Outpost**: Hold the perimeter against waves of zombies.
4. 💣 **Word Bomb Defusal**: Disarm ticking explosives before the timer runs out.
5. 🌌 **Galaxy Invaders**: Retro bullet-hell space combat powered by typing accuracy.
6. 🌊 **Sub-Zero Word Falling**: Freeze falling words with quick reflexes before they reach the ground.
7. 🥷 **Ninja Shuriken Slash**: Slice flying fruit and targets with shuriken strikes.
8. 🧙 **Wizard Spell Duel**: Cast magic shields and lightning spells in a mage duel.
9. 🚀 **Cosmic Laser Strike**: Space command laser interception defense.
10. 🏰 **Castle Siege (Catapult Defense)**: Launch boulder strikes against incoming siege engines.
11. 🚢 **Abyss Submarine (Sonar Torpedo)**: Launch guided acoustic torpedoes in the deep ocean.
12. 🎵 **Neon Synthwave Rhythm (Beat Smasher)**: Hit rhythm markers to electronic synthwave beats.
13. 🧪 **Spellcraft Alchemy (Potion Brewer)**: Brew mystical elixirs and transmutation reagents.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [Git](https://git-scm.com/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/shivam404x/typemaster-pro.git
   cd typemaster-pro
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for Production**:
   ```bash
   npm run build
   ```
   The optimized production bundle will be generated in the `dist/` directory.
